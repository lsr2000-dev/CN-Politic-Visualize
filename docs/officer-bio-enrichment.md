## 2. 数据来源与处理

1. **Wikidata SPARQL**：出生日期 P569、出生地 P19、性别 P21、民族 P172、政党 P102 + 起始时间 P580。
2. **中文维基百科正文/信息框**：补充籍贯、入党时间。
3. **百度百科（经 r.jina.ai 渲染）**：补充少量正文履历。
4. **默认规则**：
   - 性别缺失时按男性填入，已由公开履历校正女性；
   - 民族缺失时默认“汉族”，并按已知名单覆盖蒙古族、壮族、维吾尔族、哈萨克族、藏族、回族等；
   - 不把“未知”写成具体日期。
