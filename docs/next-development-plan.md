# 下一阶段开发计划

> 起点：v1.0.0（2026-11-16）
> 原则：先补数据，再接地方，最后扩展历史；不在前端硬编码事实。

## 一、阶段目标

v1.0.0 已完成二十届中央委员会及三个中央领导机构的展示。

下一阶段目标：

1. 补齐中央机构数据缺口；
2. 将统一机构接口推广到地方机构；
3. 完成机构沿革与多级机构导航；
4. 统一数据质量、来源和版本发布流程。

---

## 二、P0：中央机构数据收口

### 2.1 补齐机构正职

逐项检查当前没有正职记录的中央机构：

- 光明日报社；
- 中国日报社；
- 中国外文出版发行事业局；
- 经济日报社；
- 中国浦东干部学院；
- 中国井冈山干部学院；
- 中国延安干部学院；
- 中央社会主义学院；
- 中央直属机关事务管理局；
- 中央档案馆；
- 中央保密委员会办公室；
- 中央密码工作领导小组办公室；
- 中央空中交通管理办公室；
- 中央香港工作委员会；
- 中央澳门工作委员会。

要求：

- 有公开来源的补录；
- 无来源的标记 `verification_status`；
- 不伪造姓名、日期或职务；
- 不再用“正职空缺”之类的占位文案。

### 2.2 补齐人员字段

优先补齐中央委员会、政治局、书记处人员的：

```text
gender
ethnicity
party_join_date
```

目标：

- 中央委员会 229 条名单字段完整；
- 政治局、书记处、政治局常委会名单字段完整；
- 缺失字段在界面显示“—”，不用推测值填充。

### 2.3 来源审计

- 每个政治局成员、书记处成员、中央委员会成员至少有一个来源；
- 开除、增选、逝世、辞职、审查必须有日期来源；
- 中央政治局级别修正、五中全会增选和除名要有来源记录；
- 更新 `source_id` 和核验状态。

## 三、P1：地方机构适配器

### 3.1 省级试点

先接一个省，不直接铺全国。

数据范围：

```text
省委
省人大常委会
省政府
省政协
省纪委监委
省法院
省检察院
```

首批字段：

```text
机构名称
机构类型
机构级别
上级机构
现任领导
机构沿革
下属机构
来源
```

### 3.2 统一接口

使用现有：

```text
GET /api/v1/institutions/{entity_type}/{institution_id}?date=YYYY-MM-DD
```

`entity_type`：

```text
province
prefecture
county
subordinate
```

要求：

- 前端不根据“中央/地方”写分支；
- 前端根据 `sections[].available` 显示 Tab；
- 地方没有“中央委员会名单”时自动隐藏；
- 地方机构沿用同一个 `InstitutionDrawer`。

### 3.3 地级、县级

省级试点通过后，再向：

```text
地级市
自治州
盟
市辖区
县
县级市
```

推进。

## 四、P2：机构沿革与多级导航

### 4.1 机构沿革 Tab

新增：

```text
成立
撤销
合并
改名
隶属关系变化
挂牌变化
```

数据结构：

```text
institution_events
  institution_id
  event_date
  event_type
  from_name
  to_name
  parent_from
  parent_to
  source_id
```

没有沿革数据时隐藏该 Tab，不显示空壳。

### 4.2 多级机构栈

- 机构 A → 下属机构 B；
- 顶部显示面包屑；
- 支持返回上级；
- 抽屉不重新打开，只切换内容；
- 浏览器后退可选接入。

---

## 五、P3：体验与可访问性

- 机构卡片正职缺数据时显示真实状态，不再使用无意义占位；
- 所有截断字段增加悬浮完整内容；
- 抽屉焦点陷阱；
- 移动端机构信息全屏化；
- 键盘操作：
  - Esc 关闭；
  - Tab 在抽屉内循环；
  - 关闭后焦点返回触发机构；
- 减少动画模式；
- 名单滚动条样式统一；
- 浮窗在小屏下的筛选栏折叠。

## 七、P5：发布与工程

- 每次发布更新 `CHANGELOG.md`；
- 版本号遵循 `MAJOR.MINOR.PATCH`；
- 数据变更和页面变更分开记录；
- CI 固定执行：

```bash
python scripts/validate_all.py
cd backend && pytest -q
cd frontend && pnpm build
```

- 发布前生成：
  - 数据快照；
  - API 示例；
  - 页面截图；
  - 已知问题清单。
