- 地图左上角“中央领导机构”四宫格 + 其他中央机构条；
- 四套班子独立点击：党中央、全国人大、国务院、全国政协；
- 其他中央机构：两高、群团、军委、纪委监委、议事协调；

- 国务院按“总理 → 副总理/国务委员/秘书长 → 组成部门/直属机构/直属事业单位/特设机构”分层；
- 军委按“军委领导 → 军委机关/五大战区/军兵种”分层；
- 战区/军种双主官：司令员 + 政治委员分别显示；
- 议事协调机构与办公室作为父子节点，办公室独立收录；
- 每个机构负责人显示“中央委员/候补委员”徽标；
- 政治局/常委会/书记处成员显示“政治局常委/委员/书记处书记”身份与主要任职，不显示中央委员徽标；
- 点击机构打开完整席位沿革抽屉，可点击姓名进入官员档案；
- 中央组织架构改为纵向层级图，带连接线和缩放控制；
- 当前正职覆盖 **186 / 187**，唯一缺口为联勤保障部队当前双主官（公开信息显示空缺）；
- 已开除/已退休/任期结束按时间点显示“原… · 已开除”等状态；
- 官员档案、官员名册、中央机构负责人卡片均接入中央委员徽标；
- 已匹配 18/19/20 届中央委员、候补委员名单中的 **239 名数据库官员**（不是全体 332 人）。
