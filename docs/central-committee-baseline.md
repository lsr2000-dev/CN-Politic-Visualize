# 二十届中央委员会侧边栏基线

## 范围

本基线只覆盖：

- 第二十届中央委员会；
- 2022-10-23 至 2026-10-29；
- 中央委员、中央候补委员及其届中身份变化。

第十八届、十九届暂不套用，等待确认。

## 固定口径

```text
中央委员：
初始 − 离任 + 递补 = 现任
现任 − 审查中 = 可出席

中央候补委员：
初始 − 离任 − 被递补 = 现任
现任 − 审查中 = 可出席
```

## 名单收录

```text
中央委员累计名单：229 人 = 初始 205 + 递补 24
中央候补委员名单：171 人
去重合计：376 人
```

去重规则：

```text
24 名递补为中央委员的候补委员，只计一次
姓名异体字按 person_id 优先、归一化姓名兜底
```

## 离任原因

```text
中央委员：开除 36、辞职 1、逝世 1
中央候补委员：开除 14、撤职 1
```

## 状态日期规则

- 开除、辞职、逝世：从正式状态日期起不再计入可出席；
- 审查中：从被审查日期起不再计入可出席，但在现任中保留；
- 递补：从全会日期起计入中央委员，并停止计入候补委员；
- 未来才发生的状态不得提前扣除。

## 数据完整性

- 中央委员 229 条、候补委员 171 条均有出生年和籍贯；
- 名单行保留已离任人员，不因状态变化消失；
- 名单收录情况与统计数字分开显示。
