# 信息收集与交叉核对规则

**版本**：2026-11-14  
**适用范围**：四套班子正职、副职与官员履历

## 1. 来源分级

| 级别 | 来源 | 用途 |
| --- | --- | --- |
| A | 新华社、人民日报、中国政府网、中央纪委国家监委网站 | 最终确认 |
| A | 省级人大常委会公报、省级政府官网、省级政协官网 | 任免/选举日期确认 |
| B | 中国经济网省级人物库、人民网地方领导资料库、新华网地方频道 | 简历与任免线索 |
| C | 中文维基百科、百度百科 | 仅用于发现线索，不作为唯一依据 |
| D | 新闻聚合、自媒体 | 不采用 |

## 2. 硬规则

1. **正职优先 A 级来源**：省委书记、省长/主席/市长、人大主任、政协主席的任免，至少一个 A 级来源。
2. **双源交叉**：关键节点（到任、离任、代理、主持工作）至少两个独立来源；冲突时 A 级优先，并在备注中记录冲突。
3. **不伪造空缺**：没有正式正职时，写“主持工作”的副职，不把副职写成正职。
4. **不伪造日期**：
   - 有确切日 -> `day`
   - 只有月份 -> `month`
   - 只有届次 -> `term`
   - 只有现任名单 -> `snapshot`
5. **不把后续事件写成任期结束原因**：双开、审查、病逝等是个人事件，不是任期结束原因。
6. **缺口显式化**：查不到就留缺口并在覆盖报告中列出，不用猜测人名填空。

## 3. 山西案例：9 个月空档到底是谁

用户指出“山西省委书记 9 个月空缺，应由蓝天立担当”。核对结果：

- **蓝天立**：广西壮族自治区政府主席、党委副书记，2026 年被开除党籍；公开履历中没有山西省委书记任职。
- **蓝佛安**：2022 年 12 月至 2023 年 9 月任山西省委书记，2023 年 10 月唐登杰接任；这正是此前的 9 个月空档。

因此正确补位是 **蓝佛安**，不是蓝天立。此前数据的问题是：只抓了山西省委书记的部分节点，漏掉了蓝佛安整段，导致 2023-01 至 2023-09 空白。
