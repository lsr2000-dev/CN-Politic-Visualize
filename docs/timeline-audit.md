## 4. 为什么不直接用维基百科批量替换

实际抓取 124 个机构页面后，解析结果出现：

- 把历史人物（如陶铸、王首道）的结束日期错配到 2012 之后；
- 同一人重复出现；
- 政府页面的“省长”表格无法稳定抽取；
- 部分页面缺失或结构不一致。

因此**没有把自动解析结果写入数据库**。只采用可人工核对的山西完整时间线。
