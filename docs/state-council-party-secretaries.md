## 数据规则

- 分设时录入两条 `leaders` 记录：
  - 行政正职：`seat_type = minister` 或 `principal`
  - 党务正职：`seat_type = party_secretary`
- 页面统一显示完整岗位名称：
  - `外交部部长`
  - `外交部党委书记`
  - `生态环境部部长`
  - `生态环境部党组书记`
- 同一人兼任时只显示一行，不拆成两行。
