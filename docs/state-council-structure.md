# 国务院组织结构与下属机构分类

**依据**：[中华人民共和国国务院](https://zh.wikipedia.org/wiki/%E4%B8%AD%E5%8D%8E%E4%BA%BA%E6%B0%91%E5%85%B1%E5%92%8C%E5%9B%BD%E5%9B%BD%E5%8A%A1%E9%99%A2)  
**核对时点**：2026-10-29

## 分类

| 分类 | 数量 | 说明 |
|---|---:|---|
| 国务院领导机构 | 4 | 总理、副总理、国务委员、秘书长 |
| 组成部门 | 26 | 21 部、3 委员会、人民银行、审计署 |
| 直属特设机构 | 1 | 国务院国资委 |
| 直属机构 | 16 | 10 个正部级 + 6 个副部级/挂牌 |
| 办事机构 | 4 | 国务院研究室、办公厅、港澳办、台办等 |
| 直属事业单位 | 7 | 新华社、中科院、社科院、工程院、发展研究中心、气象局、行政学院 |
| 部委管理的国家局 | 17 | 均为副部级 |
| 派出机构 | 3 | 驻港联络办、驻澳联络办、驻港国安公署 |
| 其他 | 1 | 供销合作总社 |

当前国务院实际机构节点：**78 个**。
